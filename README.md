# POLYDEPT Bot

A custom Discord bot designed to help manage servers and simplify moderation tasks.

## ✨ Features

- **Message Management** — Manage messages with moderation commands.
- **Server Moderation** — Help moderators maintain a clean and organized server.
- **Custom Commands** — Built to support custom commands and future features.
- **Easy to Use** — Simple commands designed for convenient server management.

## 📋 Requirements

- [Node.js](https://nodejs.org/) (LTS recommended)
- A Discord account
- A Discord application created through the [Discord Developer Portal](https://discord.com/developers/applications)

## ⚙️ Setup

1. Clone or download this repository.
2. Install the required dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file in the project directory.
4. Add your Discord bot token:

   ```env
   DISCORD_TOKEN=your_bot_token_here
   ```

5. Start the bot using the appropriate script configured in `package.json`.

   ```bash
   npm start
   ```

## 🔒 Security

- Never share your Discord bot token.
- Never upload your `.env` file to a public repository.
- Use only the permissions required by your bot.
- Store credentials securely.
